## 本日発見した重要な知見（本に書くべき）

### 知見1：PYTHONIOENCODING=utf-8 が必須
日本語パスを含むプロジェクトで dbt Core を Windows + PowerShell から実行する場合、$env:PYTHONIOENCODING = "utf-8" を設定しないとログ・パス情報が文字化けする。
[Console]::OutputEncoding = UTF8 だけでは不十分（Pythonは見ない）。
dbt Fusion (Rust製) は元々UTF-8出力なのでこの問題は出ない可能性が高い（本計測で確認予定）。

### 知見2：Get-Content も -Encoding UTF8 必須
PowerShellの Get-Content は日本語Windowsでは CP932 デフォルト。UTF-8で保存されたファイルを読むときは -Encoding UTF8 を明示しないと文字化けする。

### 知見3：1回計測の信頼性は低い
リハーサルで Core parse のコールド平均 4.996秒 / ウォーム平均 4.101秒 と判明。差0.9秒。
過去のメモ「4.97秒（1回計測）」はコールド時の値に近いが、ウォーム時なら違う結論になる。
1回計測では「コールドかウォームか」「外れ値か」が見えない。

### 知見4：ウォーム計測の再現性が高い
ウォーム5回の標準偏差 0.032秒 = 平均の0.8%。
これだけ安定していれば Fusion との差を有意に検出できる見込み。
